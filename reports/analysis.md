# Steam 游戏市场洞察：业务分析报告

## 分析范围

面向游戏品类研究、竞品分析和数据分析岗位作品展示。数据来自 [FronkonGames / Kaggle](https://www.kaggle.com/datasets/fronkongames/steam-games-dataset) v52，版本更新时间 2026-10-02。使用 games.json，共 143,395 条原始记录，清洗后 135,162 款；口碑分析默认至少 100 条评价，共 22,808 款。标签可重叠，价格为 USD 快照价格。版本日期不代表每一条数据的抓取日期。

## 1. 游戏供给集中在哪些价格带？

全量清洗样本中，**(0,5) 美元**数量最多，为 **74,769 款，占 55.3%**。这是供给结构，不是销售结构。

| price_band | games | median_reviews |
| --- | --- | --- |
| 零价 | 20506 | 0.0 |
| (0,5) | 74769 | 6.0 |
| [5,10) | 24855 | 3.0 |
| [10,20) | 11984 | 5.0 |
| [20,40) | 2164 | 3.0 |
| 40+ | 884 | 1.0 |

业务含义：用价格带定位竞品范围，再比较题材、品质和评价量。数量多不能直接证明该价位更容易成功；零价记录也不能全部视为长期免费游戏。

## 2. 什么价位的游戏更容易获得高好评？

评价数至少 100，且价格带至少有 100 款有评价游戏时，**[5,10) 美元**的游戏好评率中位数最高，为 **85.2%**，该组 **4,526 款**。好评率 ≥90% 的比例见下表，不能将中位数直接解释为成功概率。

| price_band | games | median_positive_rate | high_rating_share |
| --- | --- | --- | --- |
| 零价 | 3005 | 80.2% | 22.7% |
| (0,5) | 11564 | 82.0% | 25.7% |
| [5,10) | 4526 | 85.2% | 33.7% |
| [10,20) | 2979 | 84.7% | 32.5% |
| [20,40) | 631 | 82.9% | 28.8% |
| 40+ | 103 | 76.1% | 22.3% |

稳健性检查：将评价门槛改为 20／100／500，在各价格带至少 100 款游戏的前提下，最高中位数价格带如下。完整结果保存在 threshold_sensitivity.csv。

| min_reviews | price_band | games | median_positive_rate |
| --- | --- | --- | --- |
| 20 | [5,10) | 8051 | 84.0% |
| 100 | [5,10) | 4526 | 85.2% |
| 500 | [5,10) | 2237 | 87.2% |

仅保留明确无折扣且至少 100 条评价的游戏时，至少 100 款游戏的价格带中，[5,10) 美元组最高，为 82.4%（1,525 款）。因此不应把全量快照的价格结论直接推广到原价市场。完整结果见 price_no_discount.csv。

在同标签、同发售年且两个价位各至少 30 款游戏的 411 个分组中，[10,20) 美元组口碑中位数高于 [5,10) 美元组的比例为 42.1%。各标签组存在重叠，不能当作相互独立的统计试验；分组控制也不能消除所有混杂因素。

业务含义：用这些分布比较同类竞品，不能推导出“提高售价就能提高口碑”。价格可能受折扣影响，高价也可能伴随更高预算、品牌和制作质量。

## 3. 哪些标签拥有更高口碑？

在评价数至少 100、标签至少 100 款游戏的条件下，**Cozy** 位于好评率中位数榜首，为 **92.8%**，包含 **281 款**。并列排名使用 DENSE_RANK，榜首不一定唯一。

| tag | games | median_positive_rate | median_reviews |
| --- | --- | --- | --- |
| Cozy | 281 | 92.8% | 492.0 |
| Wholesome | 213 | 92.7% | 452.0 |
| Cats | 326 | 92.6% | 337.0 |
| Faith | 131 | 91.3% | 365.0 |
| LGBTQ+ | 702 | 90.4% | 414.5 |
| Narrative | 203 | 90.4% | 524.0 |
| Collectathon | 347 | 90.3% | 408.0 |
| Emotional | 967 | 89.7% | 392.0 |
| Nostalgia | 134 | 89.7% | 1527.5 |
| Romance | 1055 | 89.6% | 383.0 |

业务含义：可从口碑较高、样本足够的标签中筛选竞品，再查看评价文本和具体玩法。小众高口碑不能直接解释为大市场；标签来自用户标注，也存在同义和风格标签。

## 4. 评价关注度是否集中在少数游戏？

全量清洗样本中，按评价量排序的前 **1,351 款（约 1%）贡献了 81.2% 的评价数**。这是评价关注度集中度，不是收入份额或销量份额。

业务含义：整体加权好评率会更多反映热门游戏。分析普通竞品时应同时看每游戏中位数、分位数和样本数量，避免只用爆款推断市场。

## 5. 样本中的发行数量如何变化？

2025 年发售的游戏有 **21,706 款**，相较 2024 年的样本数量变化为 **+20.1%**。使用补齐年份后的 LAG 计算同比；前一年数量为零则同比为空。2026 年不完整，不计算同比。

| 2019 | 7238 | 7451 | -2.9% | False |
| 2020 | 8740 | 7238 | 20.8% | False |
| 2021 | 10388 | 8740 | 18.9% | False |

业务含义：发行结构可用于选择竞品年份，但本数据是存量快照，可能漏掉下架游戏，不能声称覆盖完整历史市场。新游戏评价积累时间更短，所以此处使用全量样本，不加最低评价数门槛。

## 数据质量发现与局限

- CSV 表头含 DiscountDLC count，后续字段错位。AppID 496350 在 JSON 中为 252 好评、3 差评；按原 CSV 表头读取却是 0 好评、252 差评。项目使用同包 JSON，不静默修补含义不明确的列。
- 缺失价格 0 款；无评价 52,217 款；评价字段缺失 0 款；无标签 51,821 款。缺失值不填零，无评价好评率为空。
- 按名称排除 Demo、Playtest、Dedicated Server、Soundtrack。这是可审计的启发式，不能保证剔除所有工具／非正式游戏；原数据没有可靠应用类型字段。
- 不估算收入、销量或用户转化。Peak CCU 的观测窗口不明确，只在明细中展示源值，不用于实时在线趋势。
- 没有历史价格或评价快照，不能分析口碑同比、价格变化的因果效果或实时市场。
- 源数据的更新周期、存活偏差、标签重叠、评论人群选择偏差和发售时长都会影响结果。
